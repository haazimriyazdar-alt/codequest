# CodeQuest

An interactive Python quiz website with a live leaderboard, built with Flask and SQLite.

**Live demo:** https://codequest-c3ck.onrender.com

## Features
- 5-question Python quiz
- Leaderboard that saves scores in a SQLite database
- Responsive dark-theme design

## Built with
Python, Flask, SQLite, HTML/CSS, deployed on Render

## Note
The demo may take about a minute to wake up if nobody has visited recently.
